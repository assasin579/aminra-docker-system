Giải pháp

Một nền tảng. Hai phía.
Niềm tin có blockchain.

AMINRA là SaaS đa người thuê (multi-tenant) kết nối doanh nghiệp Việt với các tổ chức chứng nhận Halal quốc tế — tự động hoá bằng AI, mọi cert được anchor lên Bitcoin + Polygon, public verifier không cần đăng nhập.

⚡

AI-Assisted Documentation

OpenRouter LLM gateway (DeepSeek primary) tự động sinh 13 loại tài liệu Halal — HAS Manual, Halal Policy, 6× SOP, Process Flow, Ingredient list… Trung bình 30 giây/doc.

⌗

Multi-tenant SaaS

Schema-per-tenant (PostgreSQL) cách ly cứng — không có cross-tenant leak. 3 portal độc lập: Doanh nghiệp · Tổ chức chứng nhận · Admin. JWT + RBAC.

⛓

Blockchain-Anchored

Mỗi cert được hash SHA-256 → Merkle tree → anchor vào Bitcoin OP_RETURN và Polygon smart contract. Public verifier qua URL, không cần auth.

▣

Production-grade

62 backend tests (unit + integration + sec) · 10 frontend tests · 13 PDF templates ship · GDPR (data export/deletion built-in) · Audit log every action.

Pipeline 3-stage

  • Aggregator — pull data từ 8 nguồn (DB tenant, supply chain, audit log…)
  • Filter pipeline — 6 filters: Validation, SourceMerge, PlaceholderFiller, Format, Truncation, Watermark
  • Renderer — Playwright Chromium → PDF, metadata stripped, deterministic bytes

Governance 4-layer

  • L1 tokens (raw primitives — never used in templates)
  • L2 semantic CSS vars — what templates use
  • L3 component-level overrides per template
  • + scripts/lint-templates.sh CI check on every PR
